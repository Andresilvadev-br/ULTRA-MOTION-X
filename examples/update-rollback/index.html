Update & rollback

The update/rollback flow runs in Node against a temporary copy of a fixture project. This page shows the recorded output of examples/update-rollback/run.mjs.

ready

Run it yourself:

npm run build
node examples/update-rollback/run.mjs

Steps: install (transaction 1) → developer edits files → simulate an older installed version → update with a failing project test (automatic rollback) → fix the project → update succeeds → full rollback removes only Ultra Motion X changes and keeps the developer's edits.
